# iBackup/Restore (iBR) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A GTK4 (no libadwaita) desktop app that backs up and restores iPhones and iPads on Linux.

**Architecture:** Pure-Python core (progress parsing, device catalog, backup store, settings, command building) with no GTK imports, fully unit tested. A thin service layer runs libimobiledevice CLI tools through `Gio.Subprocess` asynchronously. The UI is plain GTK4 widgets styled by app CSS in Layan dark/light colours.

**Tech Stack:** Python 3.14, PyGObject, GTK 4.24, pycairo, libsecret (GI), libimobiledevice 1.4 CLI tools, pytest, makepkg.

**Spec:** Mockups "Mix A/B/C" on https://claude.ai/artifact/HCpAkmcXT3qRc6bCYwVdMo plus the conversation decisions recorded below.

## Global Constraints

- App name "iBackup/Restore", short "iBR"; app id `com.techxero.ibr`; executable `ibr`.
- GTK4 only. Never import or depend on libadwaita.
- Footer pill copy, exact: "Backup and restore only. Syncing and other features are not available due to licensing."
- Layan dark: bg `#34343b`, titlebar `#31313a`, sidebar `#3c3c46`, card/button `#44454b`, primary `#5657f5`, progress gradient `#716ffb` to `#4648fb`, success `#00e676`, destructive `#ff5252`, small accent text `#9a9bff`. Light variant from Layan light (`#f4f4f9` bg, `#ffffff` base).
- Passwords never on argv: pass via `BACKUP_PASSWORD` / `BACKUP_PASSWORD_NEW` env.
- Percent shown must come from idevicebackup2 output; no fake progress. Unknown phases pulse.
- Wayland-native: no X11 calls. Sleep inhibit via `Gtk.Application.inhibit`, notifications via `Gio.Notification`.
- No em-dashes anywhere. No comments that restate code.

## Decisions made in auto mode

- One backup per device per backup folder (how idevicebackup2 works: incremental into `<dir>/<UDID>`). "Keep last N" dropped. Restore can pick any device's backup in the folder via `-s SOURCE_UDID`.
- Wi-Fi devices dropped (needs netmuxd, not packaged).
- Device art drawn with cairo from a per-model geometry table (cutout type, buttons, proportions, corner radius, camera position). Finish colour: hex `DeviceEnclosureColor` when the device reports one, else the model's default finish.

## File Structure

- `ibr/core/progress.py` parse idevicebackup2 stdout into events
- `ibr/core/catalog.py` ProductType to model spec
- `ibr/core/deviceinfo.py` ideviceinfo XML plists to `DeviceInfo`
- `ibr/core/backups.py` scan backup folder into `BackupEntry` list
- `ibr/core/commands.py` argv/env builders
- `ibr/core/settings.py` JSON settings
- `ibr/core/fmt.py` size/date formatting
- `ibr/services/*` Gio subprocess runner, device monitor, operation runner, keyring
- `ibr/ui/*` window, sidebar, views, dialogs, device art, CSS in `ibr/data/style.css`
- `PKGBUILD`, `pyproject.toml`, `data/com.techxero.ibr.desktop`, `data/com.techxero.ibr.svg`

## Review Focus

- Backup cancelled mid-way: process gets SIGINT, UI returns to idle, no "success" notification.
- Device unplugged during backup: failure state shown with the tool's error line.
- Device not trusted yet: pairing state with "Unlock and tap Trust", retries until paired.
- Encrypted backup restore with wrong password: error surfaced, not silent.
- Backup folder missing or unwritable: created on demand or a clear error.

### Task 1: Core logic (TDD)

- [ ] progress parser: `ProgressParser.feed(chunk: str) -> list[Event]`; events `Phase(name)`, `Percent(value: float)`, `Bytes(done: str, total: str)`, `Finished(success: bool, message: str)`, `Waiting(passcode)`. Splits on `\r` and `\n`. Pins: `"[=====     ]  42% Finished"` gives Percent(42); `"Backup Successful."` gives Finished(True); `"Backup Failed (Error Code -4)."` gives Finished(False); `"*** Waiting for passcode to be entered on the device ***"` gives Waiting.
- [ ] catalog: `lookup(product_type: str, device_class: str) -> ModelSpec`; unknown types fall back by class.
- [ ] deviceinfo: `parse_device_info(info: bytes, battery: bytes|None, disk: bytes|None, will_encrypt: bytes|None) -> DeviceInfo`.
- [ ] backups: `scan_backups(root: Path) -> list[BackupEntry]` reading Info.plist, Manifest.plist, Status.plist.
- [ ] commands: `backup_cmd`, `restore_cmd`, `encryption_cmd`, `changepw_cmd` returning `(argv, env)`.
- [ ] settings: `Settings.load(path)`, `.save()`, defaults.
- Verify: `pytest -q` all pass.
